OBS Alert Widgets

Animated alerts for Twitch stream events

Alerts Scenes Frame Overlay Tester

How to Use

These alerts are designed to be triggered via StreamElements, Streamlabs, or any custom integration. Add a Browser Source in OBS, then use JavaScript to load the alert URL with parameters when events occur. Each alert auto-fades after the duration parameter (in seconds). Set duration=0 to disable auto-fade.

📸

New Subscriber

Polaroid camera drops in, shakes, flashes, and prints a photo with the subscriber's name.

/obs/alert-sub/
Parameters
Param Default Description
name Someone Amazing Subscriber username
label New Subscriber! Custom label text
duration 5 Seconds before fade
?name=CoolViewer&label=New%20Sub!&duration=6
