How to Use

Scene overlays are full-screen Browser Sources in OBS. Create a new scene for each stream state, add a Browser Source with the URL, and set dimensions to match your canvas (1920x1080 recommended).

Most scenes have animated backgrounds, floating elements, and themed visuals. They're designed to completely fill the screen during breaks, starting, or ending sequences.

Frame Overlay (Gameplay)

A transparent polaroid-style frame that sits on top of your gameplay. Features optional webcam frame, social buttons, REC indicator, and corner decorations. The game shows through the transparent center.

OBS Setup Tips

Browser Source Settings:
- Width: 1920 (or your canvas width)
- Height: 1080 (or your canvas height)
- FPS: 60 (for smooth animations)
- Custom CSS: Leave empty
- Shutdown source when not visible: Recommended for performance

For Portrait/TikTok (9:16):
- Width: 1080
- Height: 1920
- The frame overlay automatically adjusts layout for portrait mode
